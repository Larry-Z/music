# 吉他 · 尤克里里练习台

Go 后端 + 原生 HTML/CSS/JS 前端（Web Audio API），无前端构建步骤。

四个功能：

- **调音器**：麦克风实时识别绝对音高，音准正确显示绿色，偏低 / 偏高给出左右提示，支持吉他、尤克里里、Baritone 等调弦预设。
- **节拍器**：30–260 BPM、任意拍号（n/m）、四分 / 八分 / 三连音 / 十六分细分、每小节第一拍重音、Tap 测速。
- **节奏训练器**：常用吉他 / 尤克里里扫弦节奏型，也支持自定义循环，可选择木吉他或尤克里里音色和 1–32 个小节，每小节分别选择和弦、套用节奏型或逐格编辑扫弦。
- **和弦库**：尤克里里（标准 G-C-E-A）42 个 + 吉他（标准 EADGBE）49 个常用和弦指法图，可按乐器 / 根音 / 类型筛选，点击试听。

## 运行

```bash
go run .                 # http://localhost:8080
go run . -addr :9000     # 换端口
go run . -web web        # 开发模式：前端从磁盘读取，改完直接刷新
go build -o music .      # 构建单文件二进制（前端已内嵌）
```

麦克风需要安全上下文，请用 `http://localhost:8080` 或 HTTPS 访问。

节拍器与节奏训练的 BPM 首次打开默认为 75，修改后会分别保存在浏览器本地。

节奏训练中选择「自定义循环」，设置音色、循环小节数、拍号和每拍细分，再分别编辑各个小节。点击格子依次切换下扫、上扫、闷音和空拍；最后一个小节播放完会回到第 1 小节。小节数支持 1–32，默认 4；增加时复制末小节，减少时移除末尾小节。修改会暂停播放，自定义设置自动保存在浏览器里，刷新后恢复。

填写节奏名称后点击「保存为新节奏」，可保留多套练习。保存包含所有小节的和弦、扫弦、音色、小节数、拍号、细分和 BPM；从「已保存的节奏」选择并载入后，可以继续编辑，再点击「更新已选节奏」。保存版本与当前草稿独立，删除版本也会保留当前编辑内容。所有版本只保存在当前浏览器，不会上传服务器。

## 测试

```bash
go test ./...
node --test tests/*.test.js
gofmt -l . && go vet ./...
```

前端回归验证使用 Node 内置测试工具，无需安装依赖；网站构建和运行仍只需要 Go。测试覆盖播放调度、扫弦时序、资源释放、共享数据加载和调音结算，还检查合成音高、乐器泛音与衰减差异及高速混音峰值。真实麦克风与听感需要浏览器手测。

服务运行后，可用 `node scripts/render-audio.js /tmp/music-audio-preview` 导出吉他、尤克里里的扫弦、伴奏及 75/120/180 BPM 连续十六分 WAV；这些文件仅供试听，网站仍完全使用浏览器合成声音。

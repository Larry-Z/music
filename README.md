# 吉他 · 尤克里里练习台

Go 后端 + 原生 HTML/CSS/JS 前端（Web Audio API），无前端构建步骤。

四个功能：

- **调音器**：麦克风实时识别绝对音高，音准正确显示绿色，偏低 / 偏高给出左右提示，支持吉他、尤克里里、Baritone 等调弦预设。
- **节拍器**：30–260 BPM、任意拍号（n/m）、四分 / 八分 / 三连音 / 十六分细分、每小节第一拍重音、Tap 测速。
- **节奏训练器**：常用吉他 / 尤克里里扫弦节奏型，网格可视化，只播放按弦序合成的和弦扫弦音供跟弹。
- **和弦库**：尤克里里（标准 G-C-E-A）42 个 + 吉他（标准 EADGBE）49 个常用和弦指法图，可按乐器 / 根音 / 类型筛选，点击试听。

## 运行

```bash
go run .                 # http://localhost:8080
go run . -addr :9000     # 换端口
go run . -web web        # 开发模式：前端从磁盘读取，改完直接刷新
go build -o music .      # 构建单文件二进制（前端已内嵌）
```

麦克风需要安全上下文，请用 `http://localhost:8080` 或 HTTPS 访问。

节拍器与节奏训练的 BPM 首次打开默认为 75，修改后会分别保存在浏览器本地。
